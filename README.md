# Análisis de Consumo de Carne de Pollo (2000–2022)

## Descripción
Caso de estudio integrador desarrollado para la asignatura **Lenguajes de Programación para Analítica II** en el Politécnico Internacional. Se aplica un modelo de Regresión Lineal Múltiple para predecir el consumo per cápita de carne de pollo a partir de variables económicas.

## Herramientas utilizadas
- Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn)
- Análisis exploratorio de datos (EDA)
- Modelo de Regresión Lineal Múltiple
- Métricas de evaluación: R², MAE, RMSE

## Variables del modelo
| Variable | Descripción |
|----------|-------------|
| Y | Consumo per cápita de pollo (libras/persona) |
| X2 | Ingreso per cápita real (dólares) |
| X3 | Precio del pollo (centavos/libra) |
| X4 | Precio del cerdo (centavos/libra) |
